# details

Show everything stored for one account.

```shell
agy-auth details [options] [query]
agy-auth info [options] [query]
```

Arguments:

- `query`: Account selector (number, alias, email, ID)

Options:

- `--offline`: Skip the live plan and quota refresh; show cached data only
- `-j, --json`: Output as JSON
- `-h, --help`: Show this help
